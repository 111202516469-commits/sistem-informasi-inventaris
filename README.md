# Sistem Informasi Peminjaman dan Pengelolaan Barang Inventaris Berbasis Web

## Deskripsi

Sistem Informasi Peminjaman dan Pengelolaan Barang Inventaris Berbasis Web merupakan aplikasi yang dirancang untuk membantu proses pengelolaan data barang inventaris dan peminjaman barang secara terkomputerisasi.

Sistem ini dibuat untuk memudahkan pengelolaan data barang, kategori barang, pengguna, serta transaksi peminjaman sehingga informasi mengenai ketersediaan dan status barang dapat dikelola dengan lebih terstruktur.

## Latar Belakang

Pengelolaan barang inventaris dan pencatatan peminjaman yang dilakukan secara manual dapat menyebabkan kesulitan dalam mengetahui data barang, ketersediaan barang, status peminjaman, dan riwayat peminjaman.

Oleh karena itu, diperlukan sistem berbasis web yang dapat membantu mengelola data inventaris dan peminjaman secara terpusat.

## Tujuan

1. Membuat sistem informasi pengelolaan barang inventaris berbasis web.
2. Memudahkan pengelolaan data kategori dan barang.
3. Membantu proses pencatatan peminjaman barang.
4. Memudahkan pemantauan ketersediaan dan status barang.
5. Membuat data peminjaman lebih terstruktur dan mudah dikelola.

## Target Pengguna

### Admin

Admin bertugas mengelola data sistem, seperti:

* Data kategori barang
* Data barang
* Data pengguna
* Data peminjaman
* Status peminjaman

### Peminjam/Petugas

Peminjam atau petugas menggunakan sistem untuk melihat dan melakukan proses yang berkaitan dengan peminjaman barang sesuai hak akses yang diberikan.

## Fitur Utama

* Login dan logout

* Dashboard
